Project Documentation: Intelligent Test Case Generation Agent

Project Type: CA-3 Mini Project

Description: An automated tool that generates comprehensive test cases from source code or feature descriptions using Google Gemini and Gradio.

1. Project Overview

Problem Statement

Writing test cases manually is a time-consuming, repetitive, and error-prone process. Developers frequently skip writing adequate tests, leading to software defects in production environments.

Proposed Solution

This project implements an intelligent agent powered by the Google Gemini Large Language Model (LLM). It analyzes either source code or textual feature descriptions and automatically generates:

  • Executable unit test code targeted at specific frameworks (when code is provided).
  • Structured manual test case tables outlining steps and expected results (when a feature description is provided).

2. System Architecture

The application follows a linear client-server architecture utilizing a web-based frontend and a cloud-based LLM backend.

User Input
(Code / Description)
→
Gradio GUI
(Frontend)
→
Python Backend
(Prompt Construction)
→
Gemini API
(LLM Inference)
→
Test Cases
(Output Display)

Data Flow: User data is collected via the Gradio interface, injected into a predefined prompt template in the Python backend, transmitted to the Gemini REST API for inference, and the resulting Markdown text is rendered back in the GUI.

3. Technology Stack

  • Python 3: The core programming language used to build the application logic.
  • Gradio: An open-source Python library used to rapidly construct the interactive web-based graphical user interface (GUI).
  • Google Gemini API: The cloud-based Large Language Model service used for natural language understanding and code generation.
  • google-genai SDK: The official Python client library utilized to authenticate and communicate with the Gemini API.

4. Key Terminologies & Definitions

Artificial Intelligence & Cloud Terminology

Term Definition
Large Language Model (LLM) A deep learning algorithm trained on massive datasets capable of understanding, summarizing, and generating human language and programming code.
API (Application Programming Interface) A set of protocols that allows different software applications to communicate. We use the Gemini API to send data to Google's servers.
Prompt Engineering The practice of designing and structuring text inputs (prompts) to effectively guide an LLM to produce a desired, high-quality output.
System Instruction A directive provided to the LLM that establishes its persona and operational constraints (e.g., instructing the model to act as an "expert testing engineer").
Inference The computational process where the trained AI model analyzes the prompt and generates its response.

Software Testing Terminology

Term Definition
Test Case A specific set of conditions or variables under which a tester determines whether a system satisfies requirements or functions correctly.
Unit Test A software testing method where individual units or components of a software (such as a function) are tested in isolation.
Positive Testing Testing conducted using valid input data to verify that the application behaves as expected under normal conditions.
Negative Testing Testing conducted using invalid or unexpected input data to ensure the application handles errors gracefully without crashing.
Boundary Value Analysis A testing technique focusing on the extreme edges of input ranges, where defects are most likely to occur.

5. Code Walkthrough

The application is contained entirely within app.py. Below is an explanation of the core components.

1. API Configuration

import gradio as gr
from google import genai

GEMINI_API_KEY = "your-api-key-here"
client = genai.Client(api_key=GEMINI_API_KEY)

The google-genai SDK is imported and initialized using the API key to authenticate requests.

2. Prompt Templates

CODE_USER_PROMPT = """Analyze the following {language} code and generate comprehensive test cases using the **{framework}** testing framework.

```{language}
{code}
```"""

String formatting is used to dynamically inject user selections (language, framework, and code) into the prompt before transmission.
